Stopwatch for YouTrack

A Chrome extension that adds a one-click stopwatch to YouTrack time tracking. Pick an issue, start the clock, stop it, and your time is logged as a YouTrack work item. Your token is stored encrypted, and no data goes anywhere except your own YouTrack server.

  • Issues from the page you are on, plus search across YouTrack as you type
  • Start/stop, edit start time, choose work type
  • Offline queue with automatic retry
  • Recent work by week and day
  • Works in the toolbar, or inside YouTrack app windows
